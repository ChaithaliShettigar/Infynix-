# CraftBridge

CraftBridge is a handmade marketplace connecting customers with local artisans and Karnataka craft traditions.

## Demo

[Open the live demo](https://frontend-rust-nine-91.vercel.app/)

## Features

### Discover and shop
- Browse, search, and filter handmade products by craft, maker, or name.
- View product details, delivery estimates, verified craft passports, and FairCraft price breakdowns.
- Save products and manage a shopping cart.
- Meet verified artisans through profiles, ratings, locations, order history, and craft stories.
- Buy products through a demo checkout flow.

### Custom commissions
- Describe a custom idea with text, voice, or inspiration uploads.
- Select product and design details, then receive artisan matches.
- Compare proposals by price, delivery time, materials, and included progress updates.
- Approve a proposal, communicate with the artisan, and track the making journey.
- Receive progress updates and photos throughout production.
- Cancel eligible custom orders and receive refund status information.

### Buyer account
- Use one account for buying, selling, and account management.
- View orders, confirmations, tracking, notifications, reviews, and saved interests.
- Chat with artisans and buyers from one shared inbox.
- Translate messages into Kannada, Hindi, or English.
- Use voice guidance and accessibility preferences.
- Receive optional backup offers when a similar cancelled commission becomes available.

### Artisan workspace
- Register as an artisan with craft details, evidence uploads, language selection, and facilitator assistance.
- Create, preview, edit, and manage product listings.
- Review custom requests and build proposals.
- Manage production stages from accepted order to shipment.
- Upload progress updates for buyers.
- View transparent FairCraft earnings and payment breakdowns.
- Find CraftCircle bulk opportunities and submit proposals.
- Re-offer eligible cancelled pieces to interested buyers through the backup buyer pool.
- Maintain a craft story and digital passport with origin, materials, techniques, and process evidence.

### Bulk orders and support
- Create and review Karnataka-themed bulk gift requests for companies, hotels, and event planners.
- Manage quantities, group proposals, quality checks, and dispatch.
- Access facilitator tools for artisan verification, listing review, order support, translation, and assisted access.
- Use FAQs, language options, voice support, and read-aloud actions.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Build the project with:

```bash
cd frontend
npm run build
```

Checkout uses simulated payment only; no real payment is processed.
